# ProductLens

Search 121,549 Amazon Berkeley Objects products by describing them or by showing a photo. A fine-tuned CLIP (ViT-B/32)
model and an IVF-PQ index run entirely in your browser with ONNX Runtime Web (INT8). No server, and your photo never
leaves your device.

Code: https://github.com/ranjeet258/ProductLens
